# Changelog

All notable registry changes are documented here.

## 0.1.0 — 2026-11-22

- Initial public Entity Registry structure.
- Added the canonical Person identity and six shared DIO/ODI project, vocabulary, software and service identities.
- Defined authority boundaries with the Reference Model's SKOS vocabulary, publication metadata and keyword registry.
- Added JSON Schema, Python validation and GitHub Actions CI.
- Marked the initial dataset as `draft` pending review and explicit adoption by consuming projects.
